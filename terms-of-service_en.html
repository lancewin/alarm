2. App Description

This is a smart alarm app with system-level alarm scheduling (AlarmKit on iOS 26.1+, local notifications on earlier versions) that requires no registration or login and stores data locally.

3. Subscription Service

  • Monthly $0.99 / Quarterly $1.99 / Yearly $5.99
  • Auto-renewing, charged 24 hours before period ends
  • Cancel in Settings → Apple ID → Subscriptions
  • Free features (no subscription): up to 5 alarms, single-date alarms, default ringtones, custom ringtones (imported from Files / Share sheet), vibration, snooze, temporary alarms, calendar view
  • Pro features (subscription required): multi-date ringing — set multiple ring dates on the same alarm, and unlimited alarms
