캘린더 알람·지정 날짜 울림 지원

기능 설명

알람 기능

  • AlarmKit 기반 시스템 수준 알람 스케줄링으로 무음 모드와 방해 금지 모드에서도 울림
  • 여러 알람 관리: 생성·편집·삭제·활성·비활성 지원
  • 날짜별 울림: 각 알람에 하나 이상의 울림 날짜를 체크하면 선택한 날의 설정 시간에 정확히 울림
  • 날짜 빠른 선택: 향후 1개월／1년의 평일·주말·모든 날을 한 번의 탭으로 체크
  • 다시 알림: 1~30분 간격 및 최대 다시 알림 횟수 설정 가능
  • 벨소리: 시스템 기본 벨소리 + '파일' App 또는 공유 시트에서 가져온 사용자 지정 벨소리(mp3/m4a/wav/aiff/caf 등, 30초 이하로 자동 자름 후 반복)
  • 진동: 단독 또는 벨소리와 함께 사용 가능

임시 알람

  • 울린 후 자동 삭제되는 일회성 알림
  • 미리 설정된 분류: 회의, 번개 세일, 요리, 마중, 사용자 지정
  • 일회성 상황에 적합하며 일반 알람 목록을 차지하지 않음

위젯

  • 홈 화면 위젯에 다음 알람 시간 표시
  • App Group 을 통해 공유되어 앱을 열지 않아도 확인 가능
  • 소형·중형·대형 3가지 크기 제공

위젯을 홈 화면에 추가하는 방법

  1. iPhone 잠금을 해제하고 홈 화면 빈 곳을 길게 누르거나(또는 기존 위젯을 길게 누르면) 아이콘이 흔들리고 "편집 모드"가 될 때까지 기다립니다.
  2. 화면 왼쪽 위 "+" 버튼을 탭하여 위젯 갤러리를 엽니다.
  3. 검색창에 "캘린더 알람"을 입력(또는 본 앱을 아래로 스크롤)하여 위젯 목록을 엽니다.
  4. "다음 알람"에서 좌우로 스와이프해 소형／중형／대형 크기를 확인한 뒤 "위젯 추가"를 탭합니다.
  5. 홈 화면에 떠 있는 상태로 나타나면 원하는 위치로 드래그하고 오른쪽 위 "완료"를 탭합니다.

추가 후 위젯은 "다음 알람" 시간과 남은 시간을 표시하며, 앱에서 설정한 알람에 맞춰 자동 업데이트됩니다(데이터는 App Group으로 동기화되어 앱을 열 필요 없음). 데이터가 보이지 않으면 앱을 한 번 열어 동기화하세요.

멤버십 혜택

  • 여러 날짜 울림(Pro): 같은 알람에 여러 울림 날짜 설정
  • 무료 버전은 알람 최대 5개, 멤버십 가입 시 개수 무제한
  • 단일 울림 날짜 알람, 사용자 지정 벨소리, 임시 알람, 다시 알림, 진동, 위젯은 모든 사용자에게 무료

구독 관리

  • 월간／분기／연간 플랜 제공. 연간 플랜은 14일 무료 체험이 포함되며 자동 갱신되고 언제든 취소 가능
  • 구독은 자동 갱신되며 언제든 취소 가능
  • '설정 → Apple ID → 구독'에서 관리·취소
  • '구매 복원'으로 이미 구매한 멤버십 권한 복원

자주 묻는 질문

Q: 무음 모드에서도 울리나요?

A: 네. AlarmKit 기반 시스템 수준 알람이므로 무음 모드와 방해 금지 모드에서도 정상적으로 울립니다.

Q: 앱을 종료해도 울리나요?

A: 네. 시스템 수준 알람은 앱이 완전히 종료되어도 정시에 울립니다.

Q: 구독은 어떻게 자동 갱신되나요?

A: 기간 종료 24시간 전에 자동 갱신되며, Apple ID 에 연결된 결제 수단으로 청구됩니다. 갱신을 원하지 않으면 종료 최소 24시간 전에 취소하세요.

Q: 구독을 취소하려면?

A: '설정 → Apple ID → 구독'에서 이 앱을 선택하고 '구독 취소'를 탭합니다. 취소 후에도 현재 기간 동안은 멤버십 혜택을 이용할 수 있습니다.

Q: 구매를 복원하려면?

A: 구독 화면에서 '구매 복원'을 탭하면 Apple ID 가 확인되고 구매한 멤버십이 복원됩니다.

Q: 무료 체험 기간은 어떻게 계산되나요?

A: 연간을 처음 구독하는 경우 14일 무료 체험이 제공됩니다. 체험 기간 중에는 언제든 취소할 수 있고 요금이 청구되지 않습니다. 체험 종료 후 유료 구독이 자동 시작됩니다.

Q: 데이터가 서버에 업로드되나요?

A: 아니요. 모든 알람 데이터는 오직 귀하의 기기 내(SwiftData)에만 저장되며 어떤 서버로도 업로드되지 않습니다.

Q: 내 벨소리를 가져오려면?

A: '벨소리 선택'에서 '파일에서 가져오기'를 탭하여 '파일' App 에서 오디오(mp3/m4a/wav/aiff/caf 등)를 선택합니다. 다른 App 의 공유 시트에서 'CalAlarm 에 복사'를 선택할 수도 있습니다. 오디오는 기기 내에서 30초 이하의 반복 벨소리로 트랜스코딩되어 저장되므로 앱이 종료되어도 알람 시점에 내 벨소리가 재생됩니다. 저작권 보호된 Apple Music 곡은 DRM 제한으로 가져올 수 없습니다.

Q: '이 날만 울리게' 설정하려면?

A: 알람 편집에서 '울림 날짜'를 탭해 날짜 선택 화면을 열고 하나 이상의 날짜를 체크합니다(향후 1개월／1년의 평일·주말·전체 빠른 선택 사용 가능). 여러 울림 날짜 선택은 Pro 멤버십 기능입니다.

Q: 위젯이 "알람 없음"이거나 업데이트되지 않아요

A: 위젯 데이터는 App Group을 통해 앱과 동기화됩니다. 먼저 앱을 한 번 열어 동기화한 뒤 홈 화면으로 돌아가세요. 그래도 안 되면 위젯을 길게 누르고 "새로고침"을 고르거나 삭제 후 다시 추가하세요. 위젯은 15분마다 자동 새로고침되며 iOS 16 이상이 필요합니다.

Q: 위젯은 어떤 크기를 지원하나요?

A: 소형·중형·대형 3가지: 소형은 다음 알람 시간만, 중형·대형은 남은 시간과 라벨도, 대형은 앱에서 관리 안내까지 표시합니다.
