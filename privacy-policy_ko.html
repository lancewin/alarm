캘린더 알람·지정 날짜 울림 개인정보 처리방침

이 앱은 귀하의 어떤 개인 데이터도 수집·업로드·분석하지 않습니다. 귀하의 데이터는 귀하의 것이며 오직 귀하의 기기에만 존재합니다.

개인정보 보호 약속

  • 회원가입·로그인 불필요 —— 계정 생성이 필요 없습니다
  • 서버 없음 —— 데이터를 받는 서버를 운영하지 않습니다
  • 개인 데이터 수집 안 함 —— 이름／전화번호／위치 정보를 얻지 않습니다
  • 데이터 업로드 안 함 —— 데이터는 기기 내에만 저장
  • 제3자 추적 없음 —— 광고／분석 SDK 가 없습니다
  • 광고 없음 —— 광고 수익화를 일절 하지 않습니다

권한 사용

  • 알람 권한(NSAlarmKitUsageDescription): AlarmKit 기반 시스템 수준 알람 스케줄링을 위해 사용하며, 무음 모드와 방해 금지 모드에서도 정시에 울리도록 합니다
  • 파일 가져오기(시스템 '파일' App／공유 시트): 사용자 지정 벨소리를 선택할 때 직접 선택한 오디오 파일을 읽고 기기 내에서 트랜스코딩하여 알람음(App 샌드박스의 Library/Sounds)으로 저장합니다. 오디오는 기기 내에만 저장되며 어떤 서버로도 업로드되지 않고 다른 용도로 사용되지 않습니다

구독 및 결제

  • 결제는 Apple App Store 가 처리하며, 당사는 결제 정보에 접근하거나 저장하지 않습니다
  • 구독은 Apple ID 에 연결되며 별도 계정 시스템이 없습니다
  • 월간／분기／연간 플랜 제공. 연간 플랜은 14일 무료 체험이 포함되며, 체험 종료 후 자동 갱신되고 언제든 취소 가능합니다

App Group 공유

  • 홈 화면 위젯에 다음 알람 시간을 표시하기 위해서만 사용
  • 공유되는 것은 다음 알람의 발동 시각뿐이며 다른 데이터는 포함되지 않습니다
  • 데이터는 기기 내 App Group 컨테이너 내에서만 전달되며 외부나 서버로 전송되지 않습니다

데이터 저장

  • 모든 알람 데이터는 기기 내(SwiftData)에 저장
  • '파일' App 이나 공유 시트에서 가져온 사용자 지정 벨소리 오디오 파일은 기기 내(Library/Sounds)에 저장되며 앱 삭제 시 함께 제거
  • 앱을 삭제하면 기기 내 모든 데이터가 삭제됩니다

제3자 서비스

  • 이 앱은 어떤 제3자 분석 SDK 도 사용하지 않습니다
  • 이 앱은 어떤 제3자 광고 SDK 도 사용하지 않습니다
  • 이 앱은 어떤 제3자 추적 구성요소도 포함하지 않습니다
