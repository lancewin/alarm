CalAlarm · Date Alarm Политика конфиденциальности

Это приложение не собирает, не загружает и не анализирует ваши личные данные. Ваши данные принадлежат вам и хранятся только на вашем устройстве.

Обязательства по конфиденциальности

  • Без регистрации и входа —— не нужна учётная запись
  • Без сервера —— данные не передаются на сервер
  • Не собирает личные данные —— нет имени/телефона/местоположения
  • Не загружает данные —— хранение только локально
  • Без стороннего отслеживания —— нет рекламных/аналитических SDK
  • Без рекламы —— монетизация через рекламу отсутствует

Использование разрешений

  • Разрешение будильника (NSAlarmKitUsageDescription): для системного планирования через AlarmKit, чтобы будильник звучал в беззвучном режиме и «Не беспокоить»
  • Импорт файлов (App «Файлы»/лист общего доступа): при выборе своего рингтона приложение читает выбранный аудиофайл и локально перекодирует его (Library/Sounds). Аудио остаётся на устройстве, не загружается на сервер

Подписка и оплата

  • Оплату обрабатывает App Store; мы не видим и не храним платёжные данные
  • Подписка привязана к Apple ID; отдельной учётной записи нет
  • Месячный/квартальный/годовой планы; годовой включает 14 дней бесплатно, автопродление, отмена в любое время

Общий доступ App Group

  • Используется только для показа следующего будильника в виджете
  • Передаётся только время следующего будильника
  • Данные в локальном контейнере App Group, никогда не отправляются на сервер

Хранение данных

  • Все данные будильника хранятся локально (SwiftData)
  • Импортированные рингтоны локальны (Library/Sounds), удаляются при удалении приложения
  • При удалении приложения все локальные данные стираются

Сторонние сервисы

  • Никаких аналитических SDK сторонних разработчиков
  • Никаких рекламных SDK сторонних разработчиков
  • Никаких компонентов отслеживания сторонних разработчиков
