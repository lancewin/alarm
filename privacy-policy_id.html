CalAlarm · Date Alarm Kebijakan Privasi

Apl ini tidak mengumpulkan, mengunggah, atau menganalisis data pribadi apa pun. Data Anda milik Anda dan hanya ada di perangkat Anda.

Komitmen privasi

  • Tanpa daftar tanpa login —— tidak perlu akun
  • Tanpa server —— tidak ada server yang menerima data
  • Tidak mengumpulkan data pribadi —— tidak ada nama/telepon/lokasi
  • Tidak mengunggah data —— hanya disimpan lokal
  • Tanpa pelacakan pihak ketiga —— tidak ada SDK iklan/analitik
  • Tanpa iklan —— tidak ada monetisasi iklan

Penggunaan izin

  • Izin alarm (NSAlarmKitUsageDescription): untuk penjadwalan sistem via AlarmKit, berbunyi dalam senyap dan Jangan Ganggu
  • Impor file (App "File"/lembar bagikan): saat memilih nada sendiri, app membaca file audio dipilih dan transkode lokal (Library/Sounds). Audio hanya di perangkat, tidak pernah diunggah

Berlangganan dan pembayaran

  • Pembayaran oleh App Store; kami tidak melihat atau menyimpan data pembayaran
  • Berlangganan terikat Apple ID; tidak ada akun terpisah
  • Paket bulanan/triwulan/tahunan; tahunan ada 14 hari gratis, auto, batalkan kapan saja

Berbagi App Group

  • Hanya untuk menampilkan alarm berikutnya di widget
  • Hanya waktu alarm berikutnya dibagikan
  • Data di wadah App Group lokal, tidak ke server

Penyimpanan

  • Semua data alarm lokal (SwiftData)
  • Nada impor lokal (Library/Sounds), hapus saat uninstall
  • Uninstall hapus semua data lokal

Layanan pihak ketiga

  • Tidak ada SDK analitik pihak ketiga
  • Tidak ada SDK iklan pihak ketiga
  • Tidak ada komponen pelacakan pihak ketiga
